МедАссистент 🏥
МедАссистент — это веб-приложение для сбора анамнеза пациентов перед приёмом врача с использованием ИИ для генерации уточняющих вопросов.

📖 Описание
Приложение позволяет:

Врачу:
Редактировать список вопросов для пациентов
Включать/выключать генерацию ИИ-вопросов
Просматривать результаты опросов
Получать ИИ-анализ ответов пациента
Добавлять комментарии к опросам
Пациенту:
Проходить опрос перед приёмом
Отвечать на вопросы доктора
Отвечать на 3 уточняющих вопроса от ИИ (если включено)
ИИ-ассистенту (LM Studio):
Анализировать ответы пациента
Генерировать 3 уточняющих вопроса на основе ответов
Структурировать информацию по категориям
Формировать рекомендации для врача
Выявлять подозрения на недостоверность ответов

🔌 Подключение к ИИ (LM Studio)
Приложение использует LM Studio локально для генерации ИИ-вопросов и анализа ответов.

Требования к LM Studio:
Установите LM Studio: https://lmstudio.ai/
Загрузите модель (рекомендуется русскоязычная, например, Saiga, RuGPT-3 и т.д.)
Запустите локальный сервер:
Откройте вкладку "Local Server"
Выберите модель
Нажмите "Start Server"
Порт по умолчанию: 1234
Настройка подключения:
В файле src/main/resources/application.yml:

lmstudio:
base-url: http://localhost:1234
model: local-model
Параметр	Описание	По умолчанию
base-url	URL сервера LM Studio	http://localhost:1234
model	Название модели	local-model
🚀 Запуск приложения
Требования:
Java 21+
Maven 3.8+
LM Studio (опционально, для ИИ-функций)
Установка:
# Клонируйте репозиторий
git clone <repository-url>
cd medassistant

# Установите зависимости
mvn clean install

# Запустите приложение
mvn spring-boot:run
Или используйте скрипты:

Windows: BUILD.bat
Linux/macOS: BUILD.sh
Доступ:
Роль	URL
Врач	http://localhost:8080/doctor
Пациент	http://localhost:8080/patient/start

🧠 Как работает ИИ
1. Генерация уточняющих вопросов
   После того как пациент ответил на все вопросы доктора:

Ответы пациента → LM Studio → 3 уточняющих вопроса
Промпт для ИИ:

Ты — медицинский ИИ-ассистент. Проанализируй ответы пациента
и сгенерируй РОВНО 3 уточняющих вопроса.

Цели вопросов:
1. Устранить противоречия в ответах пациента
2. Запросить уточнения по важным деталям
3. Выяснить недостающую информацию для диагноза
2. Анализ ответов
   После завершения опроса:

Все ответы → LM Studio → Структурированный анализ
Результаты:

## Анализ текста пациента: — структурированные жалобы, симптомы, препараты
💡 Рекомендации ИИ: — что ещё спросить у пациента
🚩 Подозрения: — возможные противоречия в ответах

📝 Использование
Для врача:
Откройте http://localhost:8080/doctor
Нажмите "✏️ Редактировать вопросы"
Введите вопросы (каждый с новой строки, через пустую строку)
Включите галочку "🤖 Разрешить ИИ задать 3 уточняющих вопроса"
Сохраните
Просматривайте результаты опросов в панели
Для пациента:
Откройте http://localhost:8080/patient/start
Введите ФИО и телефон
Отвечайте на вопросы по одному
Если ИИ включён — ответьте на 3 уточняющих вопроса
Завершите опрос
